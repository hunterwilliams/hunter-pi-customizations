# hunter-pi-customizations

Backup of my personal pi coding agent customizations.

> **Use any skills/prompts at your own risk.** This is how I personally work and I have backed up these skills in the case I have accidental data loss etc. Not wanting to re-invent my workflow in that case ;).

## What's in here

| Repo path | Live location | What it is |
|---|---|---|
| `pi-agent/AGENTS.md` | `~/.pi/agent/AGENTS.md` | Global agent working preferences (applied across all projects/sessions) |
| `pi-agent/prompts/check.md` | `~/.pi/agent/prompts/check.md` | Prompt template: run repo check gauntlet, triage failures |
| `pi-agent/prompts/plan.md` | `~/.pi/agent/prompts/plan.md` | Prompt template: plan mode (research + plan before changes) |
| `pi-agent/prompts/refactor.md` | `~/.pi/agent/prompts/refactor.md` | Prompt template: refactor branch changes without behavior change |

## Restoring

Copy everything back over `~/.pi/agent/`:

```bash
cp -r pi-agent/. ~/.pi/agent/
```

Or restore individual files, e.g.:

```bash
cp pi-agent/AGENTS.md ~/.pi/agent/AGENTS.md
cp pi-agent/prompts/plan.md ~/.pi/agent/prompts/plan.md
```

## Not backed up (on purpose)

- `~/.pi/agent/auth.json` — credentials
- `~/.pi/agent/models-store.json` — generated model state/cache
- `~/.pi/agent/sessions/` — session transcripts
- Paseo-managed skills (`~/.agents/skills/`) — generated by Paseo, not hand-written
